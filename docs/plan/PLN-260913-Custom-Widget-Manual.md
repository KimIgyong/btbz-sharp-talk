1. 준비 — 디자인 파일                  종류별 규격표, 업로드 절차, 공개/비공개·URL 복사, 상한(50MB)·오류 E5081~E5085, 폰트 라이선스 ⚠️
2. 만들기 — 커스텀 위젯 편집기         필드별 설명표(이름·폰트 5종·글자 크기 13~16·모서리·패널 360~480×480~720·런처 아이콘·메모),
                                        간이 미리보기의 한계, [보관함에 저장] vs [저장 후 사용함]
3. 확인·적용 — 미리보기 → 사용함        실제 위젯 미리보기(10분 토큰·고객 무영향·스토어 도메인 선행), [사용함] 즉시 반영·배포 없음,
                                        [기본 위젯으로 복귀], 사용 중 편집 경고와 "복제 후 편집" 권장 절차 ⚠️
4. 운영 — 되돌리기·이관                 이력(리비전·복원·복원의 복원) / 보관·삭제(사용 중 E5086) / 복제·이름 규칙(E5087) /
                                        패키지 내보내기·가져오기(JSON, 자산 동봉, 이름 충돌 (n)) / 설정 스냅샷과의 차이 — 비교표

7. 운영 체크리스트                      시즌 디자인 전환 절차(복제→편집→미리보기→사용함→스냅샷), 되돌리기 3수단 선택 기준
8. FAQ / 문제 해결                      "폰트가 안 바뀜"(캐시·라이브 파일·다음 세션), "미리보기가 안 열림"(도메인), "CSS 칸이 없음"(애드온),
